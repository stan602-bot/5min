# 5 Minute Countdown

A standalone, mobile-friendly countdown board. No installation, package manager, or external libraries are required.

## Run it

Open **index.html** (or **5min.html**) in a web browser.

The green, yellow and red lights turn on after **100, 200 and 300 seconds**, respectively, measured from when the page was opened. Tap any flap to open or close it. Opening the **1 minute** flap begins a 60-second countdown; it displays a completion message, then resets the flap after four seconds. Closing it early cancels the countdown.

## Publish using GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Set **Build and deployment** to **Deploy from a branch**.
3. Choose branch **main**, folder **/(root)**, then **Save**.
4. Once the Pages deployment completes, the site should be available at:
   https://stan602-bot.github.io/5min/

GitHub Pages must be enabled in repository settings; adding index.html alone does not automatically activate hosting.
